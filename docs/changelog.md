# Changelog — VideoToText AI

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- **Phase 0**: Requirements, architecture, database ERD, API specification, performance strategy, security, testing strategy, ADRs.
- **Phase 1**:
  - Spring Boot 3.5.0 backend initialized with Java 21, Maven 3.9, Flyway, PostgreSQL, Redis, RabbitMQ, S3, JWT, OpenAPI, Testcontainers.
  - Angular 17 frontend initialized with routing, SCSS, Angular Material 17.
  - Python 3.11 AI Worker skeleton initialized with Pydantic settings and Dockerfile.
  - Multi-service `docker-compose.yml` for PostgreSQL 16, RabbitMQ 3.13, Redis 7, and MinIO.
  - Nginx reverse proxy configuration with SSE streaming support.
- **Phase 2**:
  - Modular package structure across all domains.
  - Common DTOs (`ApiResponse`, `ErrorResponse`, `PageResponse`) and `BaseEntity` with JPA callbacks.
  - Standardized `ErrorCode` enum and `GlobalExceptionHandler` with automatic validation error mapping.
  - Complete baseline suite of 15 Flyway migrations (`V1` to `V15`).
  - RabbitMQ topic and dead-letter configurations, Redis template/cache manager, OpenAPI Swagger docs, and health checks.
- **Phase 3**:
  - `User`, `Role`, and `UserPreference` JPA entities with EAGER role fetching and audit timestamps.
  - `UserRepository`, `RoleRepository`, and `UserPreferenceRepository`.
  - `JwtTokenProvider` using JJWT 0.12.x for HMAC-SHA512 access token (15 mins) and refresh token (7 days) generation and validation.
  - `JwtAuthenticationFilter` and `JwtAuthenticationEntryPoint` wired into `SecurityFilterChain` with stateless session management.
  - `AuthService` handling registration with password strength regex validation, BCrypt hashing (strength 12), login, refresh token rotation, and Redis revocation tracking.
  - `UserService` managing profile updates and language/engine/mode preferences.
  - `AuthController` (`/api/v1/auth/register`, `/login`, `/refresh`, `/logout`) and `UserController` (`/api/v1/users/me`, `/me/preferences`).
  - Full MockMvc integration test suite covering registration, duplicate rejection, weak password rejection, authentication, refresh token rotation, and profile access control (19/19 tests passing).
  - Angular 17 Frontend Authentication UI:
    - Angular Material Login and Registration components with reactive forms and error handling.
    - Authenticated Dashboard with app toolbar, user menu, and quick action cards.
    - User Profile & Preferences editor for configuring default language, processing mode (local/cloud), and ASR engine/model.
    - Functional `authInterceptor` with automatic token attachment and 401 refresh token retry logic.
    - `authGuard` and `guestGuard` route protection with lazy loading.
- **Phase 4**:
  - AWS S3 / MinIO object storage service (`S3StorageService`) supporting direct uploads, chunked multipart uploads, pre-signed URL generation, and deletion.
  - Video entities (`Video`, `UploadSession`) and JPA repositories with owner-level isolation.
  - Deep file verification (`VideoValidator`) enforcing allowed extensions, 10 GB size limits, 240-minute duration limit, and binary magic bytes inspection.
  - Metadata extraction (`MetadataExtractionService`) using FFprobe JSON inspection with resilient fallback.
  - REST endpoints (`VideoController`): direct multipart upload, chunked upload initiation, chunk parts upload, multipart completion, paginated video listing, video details with streaming URL, and video deletion.
  - Integration test suite (`VideoControllerIntegrationTest`) covering all upload paths, format/duration/signature rejections, and access control (28/28 tests passing).
  - Angular 17 Frontend Video UI:
    - Interactive drag-and-drop file upload zone with live upload progress percentage and validation feedback (`VideoUploadComponent`).
    - Responsive video library with status filters, search, specs display, and pagination (`VideoLibraryComponent`).
    - Video detail page with HTML5 `<video>` preview player, technical metadata breakdown, and transcription CTA (`VideoDetailComponent`).
    - Configured lazy routes protected by `authGuard`.
- **Phase 5**:
  - Python 3.12 AI Worker environment configured with virtual environment (`.venv`) and pip dependencies.
  - Modular worker architecture created (`consumers`, `processors`, `providers`, `diarization`, `translation`, `summarization`, `subtitles`, `storage`, `messaging`, `models`, `config`, `health`).
  - Centralized Pydantic configuration (`WorkerSettings`) and structured correlation logging (`setup_logging`).
  - Full message schemas for job requests (`TranscriptionJobRequest`), progress events (`ProcessingEvent`), and results (`TranscriptionJobResult`).
  - Auto-reconnecting RabbitMQ client (`RabbitMQClient`) with topology declarations for exchanges, queues, and DLQ.
  - Persistent event and result publishing (`EventPublisher`).
  - Multi-stage pipeline processing lifecycle (`BaseJobProcessor`, `DefaultJobProcessor`).
  - Distributed idempotency management (`IdempotencyManager`) backed by Redis to prevent duplicate compute runs.
  - Exponential backoff retry handler (`RetryHandler`) with max retry threshold (3 retries) and dead-letter routing to `transcription.dlq`.
  - RabbitMQ worker consumer (`TranscriptionConsumer`) with manual message acknowledgments (`basic_ack`, `basic_nack`).
  - FastAPI health check & metrics server with `/health` liveness and `/health/detailed` readiness endpoints.
  - Complete pytest test suite (19/19 tests passing).
- **Phase 6**:
  - Unified ASR provider abstraction (`ASRProvider`) with schemas for `WordTimestamp`, `TranscriptionSegment`, and `TranscriptionOutput`.
  - `faster-whisper` integration powered by CTranslate2 with model selection (`tiny` to `large-v3`) and `MockASRProvider` for deterministic testing.
  - `DeviceDetector` probing CUDA acceleration, VRAM allocation, and precision selection (`float16`, `int8_float16`) with automatic `int8` CPU fallback.
  - `ASRProviderFactory` instantiating optimal providers based on runtime telemetry.
  - `AudioExtractor` extracting 16kHz mono 16-bit PCM WAV audio using FFmpeg with resilient fallback.
  - `VADChunker` chunking speech up to 10 minutes (600s) at silence boundaries.
  - `VideoTranscriptionProcessor` executing end-to-end multi-stage pipeline with global timeline offset calculation and progress event dispatching.
  - `ASRBenchmarkSuite` profiling 10m, 30m, 1h, and 4h audio workloads with Real-Time Factor (RTF) and memory telemetry.
  - Full test suite passing (30/30 pytest tests passing).
- **Phase 7**:
  - `AudioExtractor` enhanced with EBU R128 loudness normalization (`-af loudnorm=I=-16:TP=-1.5:LRA=11,aresample=16000`) for balanced acoustic dynamics before ASR.
  - `VADChunker` updated with overlap windowing (`overlap_seconds=1.0`) to eliminate boundary phoneme clipping across chunk edges.
  - `ChunkScheduler` implemented with GPU VRAM-aware concurrency bounds (1 to 4 parallel workers) and chunk-level exponential backoff retries.
  - `TranscriptMerger` implemented for chronological chunk stitching, timeline offset conversion, and boundary overlap de-duplication.
  - Backend Spring Boot 3.5.0 transcription orchestration:
    - Entities: `TranscriptionJob`, `TranscriptionChunk`, `TranscriptSegment`, `ProcessingEventRecord`.
    - Repositories: `TranscriptionJobRepository`, `TranscriptionChunkRepository`, `TranscriptSegmentRepository`, `ProcessingEventRepository`.
    - DTOs: `CreateTranscriptionRequest`, `TranscriptionJobResponse`, `TranscriptSegmentResponse`, `JobProgressEventDto`, `TranscriptionMessagePayload`, `TranscriptionResultPayload`.
    - Services: `TranscriptionService` (job submission, ownership verification, lifecycle management), `TranscriptionProducer` (publishing to `videototext.exchange` / `transcription.request`), `TranscriptionEventConsumer` (listening to `processing.events` and `transcription.results`, persisting events and updating job statuses), and `SseEmitterService` (managing thread-safe Server-Sent Events subscribers per `jobId`).
    - REST Controllers: `TranscriptionController` (`POST /api/v1/transcriptions`, `GET /api/v1/transcriptions/{jobId}`, `GET /api/v1/transcriptions`, `GET /api/v1/transcriptions/video/{videoId}`, `GET /api/v1/transcriptions/{jobId}/segments`, `POST /api/v1/transcriptions/{jobId}/cancel`) and `EventController` (`GET /api/v1/events/jobs/{jobId}` SSE stream).
    - Comprehensive integration test suite (`TranscriptionControllerIntegrationTest`) with 38/38 Spring Boot tests passing with 0 failures.
  - Angular 17 real-time transcription user experience:
    - Models & services: `transcription.model.ts`, `transcription.service.ts` with RxJS SSE `EventSource` observable stream.
    - `TranscriptionDialogComponent`: modal dialog allowing selection of language, model (`tiny` to `large-v3`), diarization, executive summary, and target translation languages.
    - `VideoDetailComponent`: live animated progress bar, active stage indicator (`AUDIO_EXTRACTION`, `VAD_CHUNKING`, `TRANSCRIBING`, `COMPLETED`), completed chunk counter, cancel job action, and interactive segment viewer with clickable timestamp seeking on the video player and search filter.
- **Phase 8**:
  - Python AI Worker speaker diarization pipeline:
    - Structured models (`DiarizationTurn`, `SpeakerProfile`, `DiarizationResult`).
    - NIST Diarization Error Rate (DER) calculator (`DiarizationMetrics.calculate_der`).
    - `BaseDiarizationEngine`, `AcousticDiarizationEngine` (pure Python vector math, zero WDAC-blocked C-extension requirements, fully offline and deterministic), and `PyAnnoteDiarizationEngine` (Hugging Face token authentication and GPU/CPU dispatch with automatic acoustic fallback).
    - `DiarizationEngineFactory` dynamically instantiating optimal diarization engine.
    - `SpeakerAssociator` calculating maximum temporal overlap between ASR segments and speaker turns with fallback to `SPEAKER_UNKNOWN`.
    - `SpeakerReconciler` cross-chunk speaker alignment using 128-dimensional cosine similarity against global speaker centroids (threshold 0.75) and dynamic centroid updating.
    - `VideoTranscriptionProcessor` pipeline integration with stage 4 (`SPEAKER_DIARIZATION`) progress publishing and segment speaker attribution.
    - Pytest test suite with 43/43 tests passing.
  - Spring Boot 3.5.0 speaker management:
    - `Speaker` entity mapped to Flyway `speakers` table (V8).
    - `SpeakerRepository`, `SpeakerResponse`, `UpdateSpeakerRequest`.
    - `SpeakerService` providing job-level speaker retrieval, video ownership verification, and speaker renaming.
    - `SpeakerController` exposing `GET /api/v1/transcriptions/{jobId}/speakers` and `PUT /api/v1/transcriptions/{jobId}/speakers/{speakerId}`.
    - `SpeakerControllerIntegrationTest` with 44/44 backend tests passing.
  - Angular 17 frontend speaker experience:
    - `speaker.model.ts` and `SpeakerService` for speaker state management.
    - Speaker filter bar with interactive chips, segment count badges, and one-click filtering.
    - Inline speaker rename prompt updating backend and live UI.
    - Stylized speaker tag chips on transcript segments with display names.
- **Phase 9**:
  - Spring Boot 3.5.0 transcript management & editor backend:
    - `TranscriptRevision` entity mapped to Flyway `transcript_revisions` table (V14) with `TranscriptRevisionRepository`.
    - `TranscriptSegmentRepository` enhanced with `Pageable` pagination, case-insensitive text search, and scoped segment lookup.
    - DTOs: `TranscriptResponse` (aggregated word counts, duration, full text, and segments), `UpdateTranscriptSegmentRequest`, `ReassignSpeakerRequest`, `TranscriptSearchResponse`, `TranscriptRevisionResponse`.
    - `TranscriptionService` methods: `getTranscript`, `getJobSegmentsPaginated`, `updateSegment` (with timestamp bounds validation and automatic revision tracking), `reassignSpeaker`, `searchTranscript`, and `getRevisions`.
    - REST Controllers: `GET /{jobId}/transcript`, `GET /{jobId}/segments` (with optional `page` & `size`), `GET /{jobId}/search?query=...`, `PUT /{jobId}/segments/{segmentId}`, `PUT /{jobId}/segments/{segmentId}/speaker`, `GET /{jobId}/revisions`.
    - Full integration test suite with 21 tests in `TranscriptionControllerIntegrationTest` and 55/55 total backend tests passing.
  - Angular 17 interactive transcript editor frontend:
    - Updated `transcription.model.ts` and `TranscriptionService` with full editor methods.
    - In-place segment editor with start/end time numeric inputs, speaker dropdown selector, text editing textarea, and save/cancel actions.
    - Synchronized video player seeking on segment click or edit.
    - Full audit revisions modal displaying change history with old and new values.
    - Production bundle verified with `ng build`.
- **Phase 10**:
  - Python AI Worker translation engine:
    - Provider abstraction (`BaseTranslationProvider` ABC) and models (`SupportedLanguage`, `TranslatedSegment`, `TranslationQualityReport`, `TranslationResult`).
    - Providers: `DictionaryTranslationProvider` (pure Python, curated English <-> Hindi and English <-> Marathi vocabularies, zero C-extensions, fully WDAC safe), `HelsinkiMarianProvider` (neural pipeline with fallback), `MockTranslationProvider`, and `TranslationEngineFactory`.
    - `TranslationQualityChecker` evaluating length ratios, Devanagari Unicode script integrity (`0x0900 - 0x097F`), and heuristic quality scoring.
    - `TranslationPipeline` batch translating segments while strictly preserving start/end timestamps and speaker attributions.
    - `VideoTranscriptionProcessor` pipeline integration with stage 5 (`TRANSLATING`) in ASR lifecycle.
    - Pytest suite with 10 translation tests (53/53 total tests passing).
  - Spring Boot 3.5.0 multilingual translation backend:
    - `Translation` entity mapped to Flyway `translations` table (V9) with `TranslationRepository`.
    - DTOs: `TranslatedSegmentDto`, `TranslationResponse`, `CreateTranslationRequest`.
    - `TranslationService` managing translation listing, retrieval, on-demand synthesis, MinIO/S3 segment serialization, and non-duplicate constraint enforcement.
    - `TranslationController` REST endpoints: `GET /{jobId}/translations`, `GET /{jobId}/translations/{language}`, `POST /{jobId}/translations`.
    - `TranslationControllerIntegrationTest` with 7 integration tests covering all paths and access control (62/62 total backend tests passing).
  - Angular 17 multilingual frontend:
    - `translation.model.ts` and `TranslationService`.
    - Language selection bar with chips for `Original [EN]`, `हिन्दी [HI]`, and `मराठी [MR]`.
    - On-demand translation generation trigger with progress indicator.
    - Synchronized video preview player seeking across all languages with preserved timestamp pills and diarized speaker badges.
    - Production bundle clean (`ng build`, 406 kB initial bundle).
